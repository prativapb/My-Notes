# 🚀 DevOps Learning & Hands-on Notes

Welcome to my **DevOps Learning Repository!**

This repository is a collection of my learning notes, practical implementations, commands, configurations, and hands-on experiences related to DevOps, Cloud Computing, and Automation.

My goal is to build strong practical knowledge of DevOps tools and technologies by learning, experimenting, documenting, and implementing real-world scenarios.

## 📚 Topics Covered

- 🐧 **Linux:** Basic to advanced commands, file permissions, user management, processes, and shell scripting.
- 🔧 **Git & GitHub:** Version control, branching, merging, pull requests, and repository management.
- ☁️ **AWS:** EC2, S3, IAM, VPC, RDS, Load Balancer, Auto Scaling, CloudWatch, Route 53, and more.
- 🐳 **Docker:** Images, containers, Dockerfile, volumes, networks, and Docker Compose.
- ☸️ **Kubernetes:** Pods, Deployments, Services, ConfigMaps, Secrets, Namespaces, and EKS.
- 🏗️ **Terraform:** Infrastructure as Code (IaC), providers, resources, variables, modules, and state management.
- 🔄 **CI/CD:** Jenkins, GitHub Actions, build pipelines, deployment automation, and continuous integration.
- 📊 **Monitoring & Logging:** CloudWatch, monitoring, troubleshooting, and log management.
- ⚙️ **Shell Scripting:** Automation using Bash scripts and Linux utilities.

## 🎯 Repository Objectives

- Document my day-to-day DevOps learning journey.
- Maintain frequently used commands and configurations.
- Practice real-world implementation scenarios.
- Understand troubleshooting techniques and best practices.
- Build practical knowledge through hands-on projects.
- Create a quick reference guide for revision and interview preparation.

## 💡 Learning Approach

**Learn → Practice → Document → Implement → Improve**

I believe consistency and hands-on practice are the keys to mastering DevOps.
